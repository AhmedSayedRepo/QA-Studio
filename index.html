FAQ

Good to know before you install

Which AI providers are supported?

Anthropic, OpenAI, Azure OpenAI, Google Gemini, NVIDIA, DeepSeek, Qwen, or Ollama for a fully local model — add a key for any one of them in Setup.

Which test-management tools does it work with?

Azure DevOps (work items, test plans & suites), Jira + Xray (Jira issues & sprints with Xray tests), and Azure → TestRail or Jira → TestRail hybrids that read stories from Azure or Jira and write the generated cases into TestRail. You pick the backend at the top of Setup; each keeps its own credentials. (Jira + Zephyr Scale is on the way.)

Is QA Studio only for Windows?

No — there's a Windows 10/11 desktop app (install.bat installs Python automatically if needed) and an early Android app you can sideload from the qa-studio.apk button above. On Android, test generation runs on the server so it keeps going with the app closed; the automation project generator is desktop-only, since it writes a local project and pushes it with git.

Where do my tracker & AI credentials live?

Locally on your device only — encrypted with Windows DPAPI on desktop, and in the Android Keystore on mobile, where you can also require a fingerprint / PIN unlock before the app restores your session. They're only ever sent to the tracker (Azure DevOps, Jira or TestRail) and AI provider you explicitly connect — nothing is uploaded anywhere else.

Can my whole QA team use it, not just me?

Yes — use organization-aware accounts (Super Admin, Organization Manager, Member or Viewer), server-enforced permissions, project/team membership, lifecycle controls, and a readable audit trail. Administrators can also set each organization’s logo, locale, time zone and support details.

Does it cost anything beyond my AI provider?

No subscription — you bring your own AI key and pay that provider directly. QA Studio tracks the exact token usage of every call so you always know what you're spending.
